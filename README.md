# STJ Character Exporter

キャラクターの「キーワード → 表示画像」の対応関係をJSON形式で作成・出力する
SillyTavern拡張機能です。出力されたJSONは `image-display` および `right_nav_kai`
拡張機能から読み込まれます。

## 使い方

1. キャラクター作成/編集パネルを開くと「JSONデータ編集」ボタンが表示されます
2. デフォルト画像・サムネイル画像・キーワードごとの画像を設定します（画像ファイル名は
   拡張子なしで入力すると自動検出されます。カンマ区切りで複数指定するとランダム表示になります）
3. 「セーブ」でブラウザに下書きを保存、「JSON出力」で完成したJSONファイルをダウンロードします

## 出力後の手動配置が必要です（重要）

「JSON出力」でダウンロードされる `<キャラ名>_ext.json` は、**サーバーの
`addchara/<キャラ名>/<キャラ名>_ext.json` に手動で配置する必要があります。**
この拡張機能はブラウザ上でファイルをダウンロードするだけで、サーバーへの
自動アップロードは行いません。

同様に、`addchara/default.png`（全キャラクター共通のフォールバック画像）も
初回セットアップ時に手動で配置してください。この2つのアセット配置は、拡張機能の
自動更新の対象外です（拡張機能はコード的にサーバーの`addchara/`フォルダ以下を
書き込むことができないため）。

## インストール方法

1. SillyTavernの拡張機能パネルを開く
2. 「拡張機能をインストール」をクリック
3. このリポジトリのURLを貼り付けて保存

## 関連拡張機能

- `image-display` — このJSONの`image_display_extension`全体（キーワード群＋default）を読み込みます
- `right_nav_kai` — このJSONの`image_display_extension.thumbnail`のみを読み込みます
